# はじめに

## 概要

Swing Trade Analysis Toolは、日本株のスイングトレード戦略を開発・検証するためのPythonツールキットです。J-Quants APIを利用して株価データや財務データを取得し、様々なスクリーニング手法で銘柄を選定し、バックテストで戦略の有効性を検証できます。

## 必要な環境

- Python 3.9以上
- J-Quantsアカウント（無料登録可能）
- SQLite（Pythonに標準で含まれています）

## 基本的なワークフロー

1. **データ収集**
   - J-Quants APIから日次株価、上場銘柄情報、財務諸表データを取得
   - SQLiteデータベースに保存

2. **シグナル生成**
   - ファンダメンタル分析：財務指標に基づく銘柄選定
   - テクニカル分析：価格パターンや指標に基づく売買シグナル
   - 機械学習：過去データから将来の上昇確率を予測

3. **戦略検証**
   - バックテスト：過去データで戦略のパフォーマンスを検証
   - リスク分析：最大ドローダウンやシャープレシオなどの指標を計算

4. **結果分析**
   - Excel/JSONファイルへの出力
   - GUI/Webインターフェースでの可視化

## プロジェクト構成

```
swing/

├── setup_environment.py # 環境構築スクリプト

├── screening/          # スクリーニングモジュール
├── backtest/           # バックテストモジュール
├── db/                 # データベース関連
├── templates/          # Webテンプレート
└── docs/               # ドキュメント
```
